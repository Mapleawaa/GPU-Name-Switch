# GPU 名称切换器 (GPU Name Spoofer)

一款 Windows WPF 工具，通过修改注册表中的显卡设备描述（DeviceDesc），将显卡名称伪装为其他型号，以欺骗对显卡型号有限制的游戏或软件。

## 功能

- **自动识别显卡** — 通过 WMI + 注册表检测系统所有显示适配器及其 PCIe 地址
- **智能分类** — 真实 GPU（NVIDIA/AMD/Intel）自动显示，虚拟设备默认隐藏
- **预设名称库** — 内置 80+ 款常见显卡名称，支持厂商筛选和关键词搜索
- **自定义名称** — 支持手动输入任意显卡名称
- **自动备份** — 每次修改前自动将原始值备份为 JSON 文件
- **一键恢复** — 随时恢复显卡原始名称
- **系统主题适配** — 自动检测 Windows 深色/浅色模式并匹配 UI 配色
- **品牌颜色标识** — NVIDIA 绿 / AMD 红 / Intel 蓝

## 原理

部分游戏（如《三角洲行动》）的引擎会根据显卡型号自动设定渲染质量等级。将显卡名称伪装为低端型号后，引擎误判硬件能力，自动降低默认画质，从而实现：

- GPU 占用率降低约 10%
- 平均帧与 Low 帧提升
- 渲染延迟降低

> ⚠ 此操作为绕过引擎默认配置的社区手段，并非所有机器都能获得相同效果。修改前会自动备份，可随时恢复。

## 系统要求

- Windows 10 / 11 (x64)
- .NET 10.0 运行时
- **管理员权限**（修改注册表 `HKLM\SYSTEM\CurrentControlSet\Enum\PCI` 需要）

## 使用方式

1. 以管理员身份运行 `GpuSpoofer.exe`
2. 左侧自动显示检测到的物理显卡
3. 选中一张显卡 → 右侧选择伪装目标
4. 点击「应用修改」→ 重启系统后生效
5. 如需恢复：选中显卡 → 「恢复原始名称」→ 重启
